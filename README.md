# GitWorktrees — `wt`

Per-worktree DDEV environments for AI agents (WordPress · Drupal · Laravel · React): each branch gets its own URL, database and media, sized to the task, with DB change tracking, ownership leases and a warm pool.

- **Use it:** [`cli/README.md`](cli/README.md) — install as a Claude Code plugin (`/plugin marketplace add jhayunu/GitWorktrees`, `/plugin install wt@gitworktrees`) or `npm i -g @jhayar/wt`.
- **Why it works this way:** [`ARCHITECTURE.md`](ARCHITECTURE.md)
- **What's next:** [`PLAN.md`](PLAN.md) · ideas in [`BRAINSTORM.md`](BRAINSTORM.md)
- **For Claude Code:** [`CLAUDE.md`](CLAUDE.md)
